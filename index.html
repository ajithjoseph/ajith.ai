01 Building now

ThyWord

Principal Engineer · 2026

Our app. You say what's on your heart, out loud, and get back a Bible verse and a reflection. Under the hood it's a React Native app for iOS and Android and a Java Spring Boot API on AWS. Scripture retrieval runs on pgvector, and requests route across several model providers with cost tracked per request. Live since February 2026 at thywordapp.com.

Shepherd

Principal Engineer · ThyWord · 2026

Our B2B AI agent for churches, built under ThyWord. Each church gets one number its members can text. It answers from the church's own teaching and information, with citations, and hands off to a pastor when the member agrees. It runs on Gloo AI. We built the first version at the Gloo AI Hackathon in October 2026, and we're talking with churches in Jacksonville.

02 Dev tools

Tools that came out of problems we hit while building ThyWord.

EvalStack

Open source · MIT · v0.0.1

An eval framework for LLM apps, written in Python. Today it runs a prompt or a batch, scores each reply with exact match, contains or an LLM judge, and gives a pass or fail with a reason. It works with Anthropic, OpenAI or any function that returns text. Code on GitHub.

ShadowTel

Dev tool · In development

A GitHub Action that blocks a pull request when AI-written code breaks your database schema, internal APIs or architecture rules. Linters miss these. ShadowTel checks each PR against your real contracts and gives a clear pass or block. More at shadowtel.com.

03 Track record

PerfAgents

Founder · 2020 to 2025

A synthetic monitoring platform. Teams brought the Playwright, Cypress, Selenium or Puppeteer scripts they already had, and we ran them against production from AWS regions around the world, on Kubernetes or Lambda, scaled with KEDA and Karpenter. It was multi-tenant, with an environment per customer, and listed on AWS Marketplace. We grew to about 20 people, and Testing Mavens acquired the platform in April 2025.
