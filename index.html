01 Building now

ThyWord

Principal Engineer · 2026

Our app. Say what's on your heart, out loud, and get back a Bible verse and a short reflection for that moment.

  • Voice first. Tap once and talk.
  • The verse always comes from the Bible. The AI never writes it.
  • React Native on iOS and Android, with a Java Spring Boot API on AWS.
  • Scripture search on pgvector. Requests route across several model providers, with cost tracked per request.
  • Live since February 2026 at thywordapp.com.

Shepherd

Principal Engineer · ThyWord · 2026

Text your church anything, any time, and get an answer from your own church's teaching.

  • Our B2B AI agent for churches, built under ThyWord.
  • One number per church over iMessage, RCS or SMS. Every answer links to where it came from.
  • Brings in a pastor when it's more than a question, and can book the call.
  • Python, Next.js and PostgreSQL with pgvector. Replies run through Gloo AI.
  • First built at the Gloo AI Hackathon in October 2026. We're talking with churches in Jacksonville.

02 Dev tools

Tools that came out of problems we hit while building ThyWord.

EvalStack

Open source · MIT · v0.0.1

A test kit for AI apps. It checks whether the answers are right, and tells you why when they're not.

  • Runs one prompt or a batch and scores each reply with exact match, contains or an LLM judge.
  • Every result is a pass or fail with a written reason.
  • Works with Anthropic, OpenAI or any function that returns text.
  • Written in Python. Code on GitHub.

ShadowTel

Dev tool · In development

A safety check for pull requests. It stops AI-written code that breaks your team's rules before it gets merged.

  • Runs as a GitHub Action on every pull request.
  • Checks the change against your real database schema, internal APIs and architecture rules.
  • Catches what linters miss, and gives a clear pass or block.
  • More at shadowtel.com.

Founder · 2020 to 2025

A robot customer for your website. It clicked through your app every few minutes and woke up the right engineer when something broke.

  • Ran the Playwright, Cypress, Selenium and Puppeteer scripts teams already had, against production.
