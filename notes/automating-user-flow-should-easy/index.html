Automating a user flow should be easy.

Automating a user flow should be easy. Playwright is one of the best frameworks to do web automation.

But once you write the web automation scripts using Playwright you need an infra to run these scripts. Even if you want to run it periodically, it is kind of a pain in the ***.

You can spin up a Kubernetes (Official) cluster to run this. And use GitHub Actions or Jenkins or something else to schedule it. Solves the problem a bit. Good luck running Kubernetes (Official) which in itself is complex (I'm a Kubernetes Administrator and I know the complexity very well). Good luck if you can keep it inexpensive as well. To be honest, it becomes complex, expensive, a big problem in itself to maintain as well.

But does this mean you should not do web automation? No, web automation is essential to test your user flows and is even more important to test it periodically from different regions around the world.

That's the reason, there are synthetic monitoring products exists.

Now, there are a few tools that do Playwright well, but I have not found a single tool that can be like a single pane of glass view for testing and monitoring like PerfAgents does. Please tag in the comments if there are good tools that can replace PerfAgents.

PS: Don't get me started on AI agents. It's a wild topic and is really fascinating too.
