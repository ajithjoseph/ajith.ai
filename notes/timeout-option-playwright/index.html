Timeout option in Playwright.

Timeout option in Playwright.

The new timeout option in the latest release of Playwright V1.50 allows the step to fail individually. This is really going to be one of the most used features in Playwright

test('some test', async ({ page }) => {
await test.step('a step', async () => {
// This step can time out separately from the test
}, { timeout: 1000 });
});
