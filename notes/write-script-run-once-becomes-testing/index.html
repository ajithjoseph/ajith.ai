You write a script* and run it once, it becomes testing.

You write a script* and run it once, it becomes testing.

You write a script* and run it multiple times, it becomes monitoring.

You write a *script and run it in a loop from multiple locations, it becomes synthetic monitoring!

*Script can be a Playwright or a Selenium script. Or it can be a Cypress.io or a Puppeteer script.

PS: It is as simple as that.
